# Componentes

Peças da tela que aparecem em mais de um lugar: botões, avisos, selo "DEMONSTRATIVO", cartão de rota.

- Um componente por arquivo, com nome em `PascalCase` (exemplo: `BotaoGrande.tsx`).
- Nenhum texto escrito direto no componente: ele recebe o texto pronto, vindo de `src/textos/`.
- Toda cor vem junto de ícone e texto, e todo botão tem pelo menos 48 px.
