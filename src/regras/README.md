# Regras

As regras de decisão do app: funções puras (mesma entrada, mesma resposta) e com testes.

- Cada regra fica num arquivo (`escolherIdioma.ts`) e o teste fica ao lado (`escolherIdioma.test.ts`).
- Teste também o caso **sem dados** e o caso em que **a consulta falhou**.
- Para rodar os testes: `npm run testar`.
