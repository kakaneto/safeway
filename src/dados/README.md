# Dados

## pontos-de-apoio.json

Pontos de apoio curados pela turma. Regras:

- Só **lugares públicos ou de atendimento ao público** (posto de saúde, delegacia, Conselho Tutelar, CRAS, biblioteca...). Nunca a casa de alguém.
- Cada ponto precisa de **fonte** (link oficial) e **data em que foi conferido**.
- Nunca inventar: se não achou fonte, o ponto não entra.
