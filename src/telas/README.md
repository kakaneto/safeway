# Telas

Uma pasta por tela do app, com nome em `kebab-case` (exemplo: `ajuda-agora/`, `privacidade/`).

- A tela junta componentes de `src/componentes/` e mostra textos de `src/textos/`.
- Decisões ("qual rota mostrar primeiro?") não ficam aqui: ficam em `src/regras/`, com testes.
- Pedidos à internet também não ficam aqui: ficam em `src/servicos/`.
