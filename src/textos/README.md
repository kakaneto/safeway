# Textos

Todo texto que aparece na tela mora aqui, nunca direto no código.

- `pt-BR.json`: português do Brasil (padrão).
- `es.json`: espanhol.
- Os dois arquivos precisam ter **as mesmas chaves**. O teste `textos.test.ts` confere isso.
- Frases curtas e simples. Nunca use "seguro" ou "segura": diga "rota sugerida".
